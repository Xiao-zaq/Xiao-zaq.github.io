# 模型口径与数据复核

本次目标是把可执行实现与已有证据分开保存，并给下一次正式SF24物理加载提供明确接口。参考输出是实际运行结果，但其规模与模型范围不支持整篇论文的结论。

## 五个必须区分的数学对象

1. `F(path,class,departure_bin)`是每个出发单元的车辆质量。本次已读证据为107×2×241；出发路径关联总量不能恢复车辆实际入链时刻。
2. `Q_wait`是等待库存，`S_service`是服务中剩余库存。论文式(29)可描述总能量工作量的理想工作守恒递推；给定逐车功率和连接数时，站点未必能在所有低需求时段用满额定总功率。两者不能同时被当作同一个严格服务模型。
3. 等效端口是故障容量块。保持40000 kW和20块时，每块2000 kW；逐车150 kW上限与这个故障分解是不同参数。本包FCS候选模型把二者分开，不追认历史服务时钟。
4. 原公开SF24网络是76条道路的交通分配基准。当前正式104条扩展连接包括76 ROAD、20 WCL和8条FCS/EXIT连接；缺少原有序路径时，不允许把新生成路径贴上旧PathID后装载保存F。
5. 原论文中的491路径与当前107路径必须通过来源版本统一。不能按较大的数字补齐路径，再继续声称同一均衡/同一案例。

## 公开网络的单位处理

TransportationNetworks的SF24说明明确提示它不是现实网络标定。原自由流时间单位为0.01小时，乘0.6才是分钟；把原数值当分钟是另一种常见基准约定，必须另行声明。原长度被设为自由流时间的任意数值，不能直接当公里。原容量通过BPR参数反算，不能自动成为CTM硬容量。

Han等公开ND文件的列含义由其网络预处理源码核实：第3列veh/s、第4列m、第5列s。导出的`ND_HAN_REFERENCE.csv`保留原单位；转换到分钟/km时分别乘60、除1000、除60。这是公开ND参考输入，不是本研究充电扩展网络的字节替身。

## 本包固定流加载器的边界

`network.py`是连续质量、离散时间的FIFO点队列加载。道路无有限存储，因而不能产生空间回溢；单独的CTM串联组件用于验证发送/接收约束，两者尚未组成全网络LWR求解器。自由流时间向上对齐dt，所有路段在同一时刻完成推进后再接收下游流，防止按链接枚举顺序使车辆在一步中穿越多段。

WCL只在移动段计入能量。FCS服务在每个时间段内部按完成事件精确推进，但FCS到下一条网络连接的转移采用下一个dt边界，因此有0至dt的数值节点停留。固定流测试保留这一约定，不声称连续时间全网络精确解。正式运行需要dt减半对照。

FCS采用FIFO进入服务、锁定服务承诺、并行连续质量占位。不同服务量可以不同时间完成；FIFO开始顺序不要求异质任务完成顺序一致。失效降低共享总功率，已有服务不退回队列；这是一个明确的参考中断规则，必须与正式研究的服务承诺合同核对。

## VI和维修博弈

Han–Eve–Friesz的公开实现以LWR型DNL和固定点投影求解出发时刻与路径DUE。本包借鉴问题分解，不复制其求解器，采用带回溯的外梯度数值接口。新接口在每轮更新后重新计算同一点成本并报告VI gap与流量变化；不能用稳定流量替代VI收敛。

一般交通成本映射未必单调，外梯度也不保证对所有DUE收敛。当前解析两路VI只是数值组件验证。真正的滚动DUE oracle还必须接入冻结当前状态、完整候选路径、零流替代的成本以及共同随机预测情景。尚未实现的这一层不能由`solve_vi`函数存在来代替。

维修最佳响应函数使用完整收益oracle。每次偏离必须由外部调用者重做后续物理加载和残余均衡。当前验证的是可解析有限博弈，regret仅覆盖给定离散动作集；不能称为一般连续策略Nash证明。

## 结果保留和排除

P5-P3的17项原验收、12个成员hash、107路径和3620辆映射是可以保留的技术证据。导入程序使用三个本轮此前实际读取过的成员SHA256作外部锚点，再验证全部清单及数值，不接受仅凭文件名替换。

本包不纳入尚未取得原文件的P5-P2结果、135组历史MAT或仅有摘要的成本/能量结论。未认证不等于已证伪；它们仍保留在用户原目录，本包不会删除。归档成员身份也不等于FIFO、SOC、DUE或政策因果认证。

正式图M01–M08都已设置输入门槛。缺失实验不补零、不插值成结果、不用参考端口曲线顶替网络RI。正式实验列表见`EXPERIMENT_DESIGN.csv`。
